TCW Present

Three design directions for authenticated live screen sharing.

These are static product concepts for a LiveKit-backed web app: Entra-authenticated moderators, pre-created presentation codes, password-only viewer access, QR handouts, and browser-native screen selection.

Covered states

  • Moderator room control and screen switching
  • Presentation code and QR handout workflow
  • Password-only viewer entry and live stream view
  • Codec/bitrate visibility without exposing complexity
01 Control Room 02 Presentation Stage 03 Access Flow

Concept 01

Control Room

A moderator-heavy interface for reliable operation. It gives the presenter fast access to room state, current stream health, viewer count, handout data, and screen switching.

Best for club staff and planned events
